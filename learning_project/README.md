# Learning Project – Крипто‑бот с нуля

## Цель
- Понять, как собрать простой торговый бот шаг за шагом.
- Научиться работать с RSS‑лентами, AI‑анализом, получением рыночных данных и отправкой ордеров.

## План (по‑этапно)
1. **Создать структуру проекта** – папка `learning_project` и несколько файлов.
2. **Скачать новости** – `news_parser.py` (используем `feedparser`).
3. **Оценить новость** – `ai_analyzer.py` (запрос к Claude, но пока можно заглушить простым рандомом).
4. **Получить рыночные метрики** – `market_data.py` (используем `ccxt`).
5. **Сгенерировать сигнал** – `decision_maker.py` (логика баллов).
6. **Торговый модуль** – `trader.py` (открытие ордеров через `ccxt`).
7. **Главный цикл** – `main.py` (объединяет всё).

## Как начать
```bash
# Перейти в папку проекта
cd "~/Desktop/bot grid/learning_project"
# Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate
# Установить зависимости (пока только feedparser и ccxt)
pip install feedparser ccxt python-dotenv
```

После этого можно писать первый файл `news_parser.py` и запускать `python main.py`.
